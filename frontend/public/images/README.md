# 前端图片目录

所有路径都以网站根路径 `/images/...` 引用。

- `home/carousel/`：首页主视觉轮播。图片按文件名排序，建议使用 `01-`、`02-` 前缀；新增图片后重新构建或刷新开发页面即可自动加入轮播。可在同目录 `metadata.json` 中选填中文替代文本和裁切位置。
- `articles/covers/`：本地文章封面与无封面文章的轮换兜底图。新增图片会自动进入首页列表的兜底封面池；文章接口返回的封面仍然优先。
- `articles/defaults/`：文章详情等位置使用的固定默认封面。
- `avatars/`：站内静态头像和作者兜底头像。
- `pages/`：登录、个人中心、后台、异常页等页面横幅或背景图。
- `brand/`：站点图标、Apple Touch Icon 等品牌资源。
- `placeholders/`：通用占位图。

替换图片时可以直接覆盖同名文件；如果修改文件名，请同步更新 `frontend/lib/site-images.ts`。轮播图片和文章兜底封面由目录自动扫描，不需要维护数组。
